[1/5] GSM5115760
============================================================
Title: CT7.5 SCN cells run 1 (mmSCN6)
Source name: Hypothalamic Cells
Organism: Mus musculus
Molecule: total RNA
Characteristics:
  - strain: C57BL/6J
  - tissue: Brain Hypothalamus
  - age: Postnatal day 10-12
Extract protocol:
  - Brains were retrieved from mouse pups at p10-12 and cut into 300µm thick slices using a McIlwain Tissue Chopper. The slices were examined under a bright-light microscope to sort those containing optimal SCN preparations and trimmed accordingly. Single SCN cells were isolated by proteolytic enzymatic digestion using the Worthington Papain dissociation kit. To ensure the cells were properly dissociated the mixture was filtered through a 40µm mesh.
  - scRNASeq libraries were prepared using the Chromium Single Cell Controller. Cells were treated following the manufacturer's protocols using 10x Genomics ChromiumTM Single Cell 3' Library and Gel Bead Kit v2 and ChromiumTM Single Cell A Chip Kit. Final libraries were sequenced on one flow cell of an Illumina HiSeq 4000 with a read length of 26 bp for read 1 and 98 bp for read 2 to yield approximately 340 million reads per sample.
Data processing:
  - CellRanger mkfastq software was used for demultiplexing raw base call files generated by Illumina sequencers into FASTQ files
  - CellRanger count software was used for alignment (STAR), filtering, barcode counting and UMI counting.
  - CellRanger aggr software was used for aggregating cells from biologically replicate runs
  - Clustering of cells was performed by either graph-based clustering or k-means clustering methods
  - Cell Loupe Browser was used to visualise and analyse data
  - Genome_build: mm38
  - Supplementary_files_format_and_content: HDF5 files include filtered gene - barcode matrices for each sequencing run
  - Supplementary_files_format_and_content: Excel format files include abundance measurements of all genes in each cluster within CT7.5 (day) and CT15.5 (night) sequenced cells
Relations:
  - BioSample: https://www.ncbi.nlm.nih.gov/biosample/SAMN18093164
  - SRA: https://www.ncbi.nlm.nih.gov/sra?term=SRX10193900
